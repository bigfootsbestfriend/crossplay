# Deep audit checklist

A researched game page only becomes indexable once its manual.json entry has `"audited": "<date>"`.
Set it only after every item below has been checked. A thin first-pass entry is not enough: Mike's spot
checks (Oct 2026) found gaps on 6 of 7 pages.

## Per game

1. **Platforms today.** Every platform the game is currently sold or playable on, including recent ports
   (Switch 2, mobile, Mac) and editions (Enhanced/Legacy, remasters, "Definitive" versions). Check the
   publisher's site and store pages, not just IGDB.
2. **Crossplay groups.** Which platforms share matchmaking, per mode if it differs (co-op vs PvP, ranked,
   custom lobbies). Opt-out/opt-in settings, input-based matchmaking, console-only pools.
3. **Cross-generation.** PS4↔PS5 and Xbox One↔Series X|S, including backward-compatible play (a PS5 running
   the PS4 build shares the PS4 servers). Separate next-gen versions that don't.
4. **PC stores.** Steam, Epic, Xbox app/PC Game Pass, EA app, Ubisoft Connect, Battle.net, GOG, Microsoft
   Store, publisher launchers. Do they share servers? Is a publisher account required (EA, Ubisoft, SHiFT,
   Rockstar, Bungie, Activision)?
5. **Dead or changed servers.** Shutdowns (PS3/360, delisted games), crossplay added or removed by patch, and
   anything announced with a future date (write the date into the note).
6. **Cross-progression / cross-save.** Yes/partial/no, with the limits (currency, one-time migrations).
7. **Requirements.** PS Plus / Game Pass Core / Nintendo Switch Online for online play, free-to-play
   exceptions, Friend's Pass style guest access.
8. **Notable extras.** Popular co-op mods (PC only), split-screen, LAN.

## Sources

- Prefer official: publisher/developer support articles, patch notes, official blogs, platform stores,
  Xbox Wire / PlayStation Blog / Nintendo pages.
- Use reputable press (Eurogamer, PC Gamer, IGN, VGC, Nintendo Life, GamingOnLinux…) when no official page
  exists, and say so if a claim rests only on player reports.
- Never copy text; write notes in our own words. Don't use PCGamingWiki data (NC licence).

## Order

Highest search demand first (Google autocomplete for "is X cross platform" / "X crossplay"), then IGDB
popularity. Games people search for that we don't cover yet get researched and audited as new entries.
